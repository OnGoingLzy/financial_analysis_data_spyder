# 同行财务分析平台升级设计

## 目标

将同行分析从六项基础横截面对比升级为覆盖盈利、成长、现金、营运效率、资本结构和杜邦拆解的经营诊断平台。标准化数据库是唯一事实源，东方财富仅作为可替换的数据采集适配器。

## 数据架构

### 标准事实表

- `income_statements` 增加所得税、投资收益、资产减值和信用减值字段。
- `balance_sheets` 增加货币资金、存货、应付账款、流动资产、流动负债、短期借款、长期借款、所有者权益、归母净资产和商誉字段。
- 新建 `cash_flow_statements`，存储经营、投资、筹资净现金流、销售收现、资本开支和期末现金。
- `companies` 增加 `business_model`，用于区分医药制造、流通和零售等业务模式。

所有金额使用人民币元整数，百分比使用百分点，报告期使用 `YYYY-MM-DD`，采集时间使用北京时间 ISO 8601。缺失数据保持 `NULL`。

### 采集适配器

Selenium 采集器通过“标准字段 → 多个候选网页标签”的映射读取报表行，不把 XPath 和中文标签散落在业务代码中。采集结果先保留原始文本，再进入标准化写入函数；未来更换 API、公告解析或其他网站时，只需提供相同字段字典。

## 指标引擎

指标均由事实表统一计算，并返回数据完整性：

- 盈利：毛利率、营业利润率、净利率、扣非净利率及四项费用率。
- 成长：营收同比、归母净利润同比。
- 现金：经营现金流/净利润、经营现金流/收入、自由现金流。
- 营运：应收、存货、应付周转天数和现金转换周期。
- 偿债：资产负债率、流动比率、速动比率、现金短债比和利息保障倍数。
- 杜邦：ROE、净利率、总资产周转率和权益乘数。

平均资产、平均权益和平均营运资本优先使用年初与期末值；缺少期初值时返回 `NULL`，不使用单一期末值伪装平均值。

## 同行分析界面

沿用专业克制研究终端风，新增五个连续分析区：

1. 综合分位热力图：盈利、成长、效率、现金和风险五维。
2. 增长—盈利气泡图：营收增长、净利率、营收规模与现金质量。
3. 百元收入结构：营业成本、销售、管理、研发、财务费用与净利润。
4. 营运效率：应收、存货、应付周转天数与现金转换周期。
5. 现金及偿债：经营现金流/净利润、现金短债比、负债率和有息负债。

现有绝对值、中位数指数和分位模式保留。没有数据的分析区显示待补采说明，而不是空图或零值。

## 兼容与验证

- `ensure_normalized_schema` 对旧数据库执行幂等加列和新表创建。
- 旧 Python 主程序继续可运行，并增加现金流抓取。
- Python 测试覆盖解析、标准化、升级和写入。
- Node 测试覆盖指标公式和 API 缺失值语义。
- Vue 测试覆盖图表配置、空状态和红盈绿亏。
- 生产构建和真实浏览器验证作为最终交付门槛。
