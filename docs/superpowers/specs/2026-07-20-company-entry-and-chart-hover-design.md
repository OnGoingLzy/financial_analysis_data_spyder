# 公司查询入口与图表悬停修复设计

## 目标

公司分析不再默认打开任意公司，而是先进入公司查询表格，用户明确选择后再进入单家公司详情。同时修复折线图、柱状图悬停时图形消失，以及柱状图不显示当前数值的问题。

## 页面与路由

- `/companies`：公司查询主页，支持按公司名称或证券代码搜索，并按市场、行业筛选。
- `/company/:code`：保留为公司详情页，只处理用户明确选择的公司，便于收藏与分享。
- 侧栏“公司分析”固定指向 `/companies`，不再读取公司列表第一项生成默认详情地址。
- 查询结果表展示公司、代码、市场、行业和最新报告期；整行及“进入分析”操作均可访问详情页。

## 图表交互

- 折线与柱状系列显式定义普通、强调和淡出状态，悬停只突出当前数据点，不降低整条线或整根柱的可见性。
- 折线图与柱状图统一使用结构化 Tooltip，并按人民币金额或百分比格式化数值。
- 柱状图 Tooltip 显示公司名称、指标名称和当前数值；空值显示“暂无数据”。
- 延续项目既定语义：盈利/正值为红色，亏损/负值为绿色。

## 验证

- 单元测试验证 Tooltip、数值格式和 hover 状态配置。
- 组件测试验证公司检索、筛选和详情跳转目标。
- 构建测试验证 Vue、TypeScript 与路由集成。
- Python 测试与真实数据库只读核验覆盖导入批次完成状态及北京时间字段。
